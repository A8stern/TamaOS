# TamaOS

TamaOS — проект настольного тамагочи и мини-консоли на ESP32-S3, программируемой на Rust.

## Первая версия

- ESP32-S3-DevKitC-1 N16R8: 16 МБ Flash и 8 МБ PSRAM.
- Цветной SPI-экран ST7789V 2,4″, 240 × 320.
- Физические кнопки и энкодер с нажатием.
- Программно генерируемые звуки через пассивный зуммер.
- Питание через USB; аккумулятор и корпус пока не входят в прототип.
- Сборка без пайки на макетной плате с проводами Dupont.

Полный состав заказанных компонентов, артикулы Ozon, цены, электрические ограничения и план первичной проверки находятся в [docs/tamagotchi-components.md](docs/tamagotchi-components.md).

## Задумка программного обеспечения

Первая прошивка должна запускаться сразу после включения и постепенно вырасти в оболочку TamaOS:

- главный экран и меню;
- виртуальный питомец с состоянием и сохранениями;
- ввод с кнопок и энкодера;
- графика и анимации;
- простые звуки и мелодии;
- мини-игры, собранные вместе с прошивкой;
- в перспективе — модульная система игр и, при необходимости, загрузка ресурсов с внешнего носителя.

Предполагаемый Rust-стек: `esp-hal`, `embedded-graphics`, `mipidsi` и интерфейсы `embedded-storage`. Окончательный выбор между bare-metal-подходом и ESP-IDF пока не сделан.

## Ближайшие шаги

1. После получения заказа сверить маркировку и сфотографировать обе стороны модулей.
2. Подтвердить распиновку ESP32-S3, экрана, зуммера и платы ULN2003.
3. Назначить безопасные GPIO для SPI, энкодера, кнопок и PWM.
4. По отдельности проверить экран, управление и звук.
5. Объединить драйверы в минимальную прошивку TamaOS.

До физической проверки не следует считать универсальные схемы из интернета точной распиновкой полученных модулей.

## Разработка

Общие команды проекта не зависят от языка конкретного подпроекта:

```sh
make setup
make check
make test
make build
make ci
```

Контракт harness и правила регистрации будущих Rust, Python, JavaScript или других подпроектов описаны в [harness/README.md](harness/README.md).
